## 🎯 LP の方針（v3 — 2026-05-03 確定）

**正式表記：「En-Dock」**（×「endock」「ENDOCK」「en-dock」「En-Dock」は表示テキストでは使用しない）。
※ ただし URL の `/endock/`、CSS クラスの `.endock-*`、PHP変数の `$dashboard_url` 等の **内部実装識別子は変更しない**（互換性維持のため）。

**既存サイトとの完全な統一感**と、**説明資料 PDF の内容をフル反映したコンテンツの厚み**を両立させる。

### 設計の柱

1. **既存テーマのコンポーネントをフル活用**
   - `get_header()` / `get_footer()` で既存のヘッダー・フッター・グローバルナビを継承
   - `.page-header` / `.section` / `.v11-overview` / `.v11-programs` / `.v11-outcomes` / `.v11-faq` / `.process__steps` / `.trust__grid` / `.btn` など、既存 `style.css` の磨かれたコンポーネントを再利用
   - `template-parts/section-cta.php` は既存テンプレートパーツを流用

2. **LP固有の追加要素**は独自に実装
   - **ハーズバーグ二要因理論ボックス**（衛生要因 5 / 動機付け要因 3）
   - **エンゲージメント数字カード**（87% / 21% / 2.5倍）
   - **6 つの組織課題カード**
   - **5 つの特徴**（PDF p.5 準拠）
   - **設問サンプルテーブル**（5 段階評価、8 カテゴリ）
   - **アンケート 3 部構成**（属性／基本／自由記述）
   - **アンケート機能 6 項目**
   - **4 軸 × 8 カテゴリ同心円図（SVG）**
   - **ダッシュボード実物プレビュー**（iframe で `lp-endock/dashboard-sample.html` を埋め込み）
   - これらは `lp-endock/lp-endock.css` で `.endock-` プレフィックスで定義（既存クラスと衝突しない）

3. **既存サイトに溶け込む**
   - 色・フォント・余白・角丸・シャドウは既存 `:root` 変数（`--color-primary`, `--color-accent` 等）をそのまま参照
   - `.endock-` プレフィックスで衝突回避

## 🌟 En-Dock の意味（覚え書き）

- **En** = 縁（えん）／ 株式会社えんのしたの「えん」
- **dock** = 船舶のドック・人間ドック → **健康診断**のメタファー

→ 「組織の健診ステーション」というブランドイメージ。
